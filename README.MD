## Cài đặt và cấu hình

### 1. Kết nối cơ sở dữ liệu

Trong `TheDuckHospitalAPI/src/main/resources/`, sao chép [application.properties.example](TheDuckHospitalAPI/src/main/resources/application.properties.example) thành `application.properties`. Đặt địa chỉ SQL Server và tên cơ sở dữ liệu ở `spring.datasource.url`, sau đó cung cấp tên đăng nhập và mật khẩu SQL Server theo mẫu.

### 2. Lưu trữ ảnh và gửi mã xác nhận

| Dịch vụ | Chức năng | Cấu hình |
| --- | --- | --- |
| Cloudinary | Lưu ảnh và tập tin | Đặt `CLOUDINARY_URL` theo tài khoản Cloudinary của bạn. |
| Microsoft Graph | Tạo địa chỉ email cho nhân viên | Điền các giá trị `MS_GRAPH_*` trong cấu hình mẫu của API. |
| Gmail | Gửi mã OTP qua email | Đặt `SPRING_MAIL_USERNAME` và dùng mật khẩu ứng dụng cho `SPRING_MAIL_PASSWORD`. |
| Firebase | Gửi thông báo đến thiết bị | Cung cấp tệp tài khoản dịch vụ `key.json` của dự án Firebase cho API. |

### 3. Ngày dùng để kiểm thử

Để xem ca trực hoặc lịch khám tại một ngày cụ thể, đặt `settings.date` trong `application.properties`, ví dụ `settings.date=2024-05-09`. Khi bỏ thuộc tính này, hệ thống dùng ngày hiện tại.

### 4. Chạy API và giao diện web trên Windows

Dùng **JDK 17** cho API. Từ thư mục gốc, mở PowerShell và chạy:

```powershell
cd TheDuckHospitalAPI
.\mvnw.cmd spring-boot:run
```

Trong thư mục `the-duck-hospital-ui`, sao chép [.env.example](the-duck-hospital-ui/.env.example) thành `.env`. Khi API chạy trên cùng máy, dùng dòng sau:

```dotenv
REACT_APP_BASE_URL=http://localhost:8080/api
```

Mở PowerShell thứ hai tại thư mục gốc để chạy giao diện:

```powershell
cd the-duck-hospital-ui
npm.cmd install
npm.cmd start
```

Mở [trang chủ trên máy](http://localhost:3000) hoặc [trang đăng nhập](http://localhost:3000/auth/login). Giữ cả hai cửa sổ PowerShell mở trong lúc sử dụng.
